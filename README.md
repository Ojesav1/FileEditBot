# Ojesav ChatBot

A Telegram bot for file renaming and thumbnail customization.

## Features
- 📁 File renaming
- 🖼️ Custom thumbnails
- 📊 Admin panel
- ⭐ Premium users
- 🔒 Ban system

## Deployment

### Method 1: Koyeb/Railway
1. Fork this repo
2. Set environment variables in dashboard
3. Deploy!

### Method 2: VPS
```bash
git clone https://github.com/yourusername/ojesav-bot
cd ojesav-bot
pip install -r requirements.txt
python bot.py
